What’s Inside Your Android Phone? Explore Installed Apps and Their Permissions.

Most of us have no idea how many apps are on our phones. A clear list makes it easier to see what is there, what it can access and how much space it takes.

November 2026 4 min read Device guide

Actual Device Matrix Storage screen

Most phones collect apps the way drawers collect cables. Some you chose, some came with the device, and a few you forgot were there. Android Settings shows parts of the picture, but the details are spread across different screens.

Why the picture gets complicated

Versions, installers, launcher visibility, target API levels and permission declarations live in different places. Storage is hard to compare at a glance too. The result is a phone full of software that is difficult to describe with confidence.

A structured view of installed apps

Device Matrix brings supported app information into one place. Browse launcher apps, package names, versions, installers, system or user grouping and target SDK. Search and filters help you narrow the list. App sizes appear when Usage Access is granted; without it, the list still works but sizes stay hidden.

The permission analyzer shows which sensitive permissions an app declares and whether Android has granted them. That is useful context for a review, not a safety verdict. A declared permission does not prove an app is doing something wrong.

What you can explore

A searchable app list

Search by name or package, and filter All, User apps or System apps.

Versions and installers

See version, installer and target SDK details where the phone reports them.

Permission context

Review sensitive permissions an app declares and whether they are granted.

Storage awareness

Compare total app size when Usage Access is allowed. This is not a code, data and cache breakdown.

A long list is not automatically a problem. The point is to recognise what you installed, spot something you do not remember and decide what is worth reviewing.

Key message

See what is installed before you decide what to remove.

Device Matrix helps you inspect app information. It does not detect malware, revoke permissions or clean application storage. App sizes require Usage Access and show a total app size, not a code, data and cache breakdown.

Get a clearer view of your apps

Open the Apps area, search the list and review the details at your own pace.
