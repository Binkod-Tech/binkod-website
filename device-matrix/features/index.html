What the app actually does

Every screen has a job. None of them guesses.

Device Matrix is a set of small, connected tools: a live dashboard, detailed hardware screens, network and app insight, guided checks, local reports and home-screen widgets. Here is what each part covers in version 1.0.0.

The app is Android-only. Values vary by device and by what the manufacturer exposes.

Home dashboard

The current picture, while you are looking.

Home opens with a locally calculated health summary, device facts, today’s screen time and live tiles for the processor, memory, storage, battery and heat. Further tiles cover display, network, camera, sensors and connectivity. Shortcuts lead to the hardware checks and the tools.

  • Readings refresh while the screen is focused.
  • No background monitoring and no stored timeline.
  • Health is a local summary of readable checks, not a diagnosis.
  • Pro owners can rearrange, hide and reorder tiles and carousels.
Hardware detail

A closer look at the parts Android will discuss.

The hardware hub opens Device, CPU, Heat, RAM, Storage, Battery, Display, Camera and Sensors. Each screen reads what public Android interfaces report and keeps estimates and missing values clearly labelled.

  • Device and build identity, including a masked build fingerprint.
  • Processor clusters, live core clocks, GPU renderer and graphics API versions.
  • RAM, storage and battery with live graphs and available estimates.
  • Thermal status, display modes, camera characteristics and a searchable sensor list.
Network and Wi-Fi

Useful network detail, with the sensitive parts covered.

Network shows the active connection type, metered and VPN state, Data Saver, operator and roaming state, Private DNS, and the Wi-Fi link. Wi-Fi names, BSSID, IP addresses, gateway and DNS stay masked unless you briefly reveal a value.

  • Masking is on by default for network identifiers.
  • Data usage: Today, 7 days and 30 days, split by Wi-Fi and mobile.
  • Connectivity combines Bluetooth and NFC state; there is no separate screen for either.
  • Pro adds the Wi-Fi analyzer. It starts no scan and asks for no permission until Pro ownership is verified.
Apps and permissions

The apps you can see, in context.

Device Matrix lists launcher apps rather than every package on the device. Search and sorting help you find one; the detail sheet shows what Android reports about version, target SDK, installer, dates and size where access allows. The analyzer summarises the collection, and the permission analyzer groups apps by the dangerous permissions they declare.

  • App sizes, screen time and some permission analysis need the special Usage Access grant.
  • Screen time shows foreground time, not total screen-on time.
  • Declared permissions are not the same as recent use.
  • There is no APK extraction or app management.
Hardware tests

Guided checks, with the result in your hands.

The tests are the guided checks someone might run on a used phone: display and pixels, multi-touch, flashlight, loudspeaker, earpiece, proximity, light, accelerometer, charging, headset and USB audio, vibration, Bluetooth, volume buttons and microphone.

  • Start one check or run the full set.
  • Pass, fail or leave a check untested.
  • Android limitations are explained and not counted as failures.
  • Results stay on the phone and can be shared as a checklist.
  • The microphone meter is live only; no audio is recorded.
Check-up and tips

Findings, not a score to chase.

The check-up reads local settings and readings and returns plain-language findings. Where Android offers a relevant setting, the finding includes a shortcut. It does not silently change the phone, and it does not promise that a change will make the device faster or last longer.

What it can notice

Examples include an old security patch, a long screen timeout, USB debugging left on, storage or memory pressure, battery temperature and a high refresh rate.

Missing readings are skipped

If Android does not expose a value, the finding is left out and the limitation is disclosed.

The health score is a summary

It reflects the checks this phone can report. It is not a diagnosis or a guarantee about the hardware.

Tools

Small utilities that hand control back to Android.

Set an alarm or timer with a prefilled request for your clock app, open the alarm list, toggle the flashlight, play a vibration pattern, or jump into the screen and touch checks.

Alarm and timer

The clock app owns the final confirmation; Device Matrix does not silently schedule an alarm.

Flashlight

Availability depends on the hardware and the Android version.

Vibration

Short, Long and Heartbeat patterns.

Screen and touch

Jump into the same guided checks used in Hardware tests.

Reports and exports

A complete report, a clear preview and your choice of destination.

Pick report sections, build a preview, then copy the text, share it, create a PDF or — with Pro — export a custom PDF and a sanitised JSON file. The preview is the same content the export will use.

Standard PDF

Includes every available section and always hides identifying details.

Free PDF

An optional rewarded video; if it cannot load, the PDF proceeds after a short fallback.

Remove ads and Pro

Skip the video gate.

Pro custom export

Follows the “Include identifying details” switch and can add sanitised JSON.

Local only

No upload and no cloud report.

Widgets

Widgets that fit the home screen.

RAM, storage, battery and device health widgets use the readings already on the phone. Free includes 2×1 and 4×1 layouts. Pro adds the 2×2 standard layouts and the 4×2 Device Health Check. The launcher owns refresh timing and widget placement.

Free

2×1 Compact and 4×1 Detailed for RAM, storage and battery.

Pro

2×2 Standard for RAM, storage and battery, plus 4×2 Device Health Check.

Appearance

Theme, accent and units carry through to widgets.

Add from the launcher

Use the launcher’s widget picker; the app cannot place widgets for you.

Appearance and units

Make the readings easier to read.

Choose System, Dark or Light; choose an accent palette or follow the system colour. Change units for temperature, storage and memory, frequency, network speed, screen size, distance, acceleration, pressure, time and power. Pro adds the extra palettes, dashboard layout editing and Animations Off option.

Standard palettes

A choice of accent palettes, plus Follow system colours.

More with Pro

Additional accent palettes alongside the standard choices.

Motion

Android’s Reduce motion setting is respected; with Pro, Animations Off for battery save is also available.

Stored locally

Theme, units and layout stay in private app storage.

Privacy inside the app

Local by default, visible before export.

Device Matrix does not create an app account or send readings to a backend. The app masks network and build identifiers, asks for permissions only when a feature needs them, and keeps reports on the phone until you choose a destination.

The six core screens

Six screens, one reading path.

Home gives the overview; Hardware opens the details, with Thermal, Battery, Storage and Memory alongside. Slide through the cards, or switch any capture between Light and Dark without losing your place.

Use the previous and next buttons, the pagination dots, a horizontal swipe, or the left and right arrow keys to move between screens.
