Sensors

Browse every sensor Android exposes, open its details and watch live values where the sensor supports them.

The Android app is required for live information. This page describes the screen and the app's documented behaviour. It cannot read your phone's hardware, sensors or network from the browser.

Live overview Sensors /device-matrix/sensors Opens in the Android app

What this screen shows

  • A searchable list of sensors Android exposes
  • Details for each sensor
  • Live values and a graph where the sensor supports them
  • No sensor data recorded to a file

What Android may not provide

Only sensors exposed by Android are listed. Live values and graphs appear where the sensor supports them.

“Not available on this device” is a real answer. When Android or the manufacturer does not expose a value, Device Matrix shows the limitation instead of filling the gap with a guess.

Open this screen in the Android app

Live device information and hardware functionality require the Device Matrix Android app. The button below uses the documented HTTPS address for this screen. If the app is installed and Android has verified App Links for app.binkod.in on your build, the screen opens directly in the app.

Open in Device Matrix App Install from Google Play

App Links verification is performed by Android after the Play-signed build is installed. This website cannot complete or confirm that device-side verification.
